# research-toolkit

A collection of useful scripts for specific tasks in single-molecule microscopy data analysis.

This repository contains small MATLAB, Python, Fiji/ImageJ, and TrackMate-related scripts used for image preprocessing, spot tracking, intensity analysis, data filtering, visualization, and preparation of inputs for downstream tools such as SMAUG.

## Contents

The scripts include tools for:

* Batch background subtraction in Fiji/ImageJ
* Maximum intensity projection of microscopy stacks
* TrackMate-based batch spot tracking
* Track and spot filtering using segmented cell masks
* Preparing SMAUG-compatible input files
* Plotting bound-time distributions
* Comparing spot intensity distributions
* Measuring fluorescence intensity as a function of cell size
* Comparing signal intensity between two strains

## Important Note

These scripts are shared as useful research utilities, but they are not fully refactored, optimized, or generalized. The goal of this repository is to provide a reference collection of utility scripts used in our research workflows. The scripts can be refactored, improved, or adapted later based on future needs.


## Usage

Before running any script, check the corresponding documentation and update file paths, parameters, and filenames as needed.
